# storyboard-studio

Website: https://579lvv.github.io/storyboard-studio/

This repository is the independently deployable static website. `preview.html` is used by the resume when present.

The source project and build script are maintained locally in `portfolio.vv`; run `split_pages.py --sites storyboard-studio` to rebuild this site. GitHub Pages serves `main` from the repository root. AI backend services are not hosted by Pages.
